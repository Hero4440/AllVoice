Ethics Rules — The Challenge Constraint

The Ethics Logic Gate is a pure, deterministic function — same inputs always produce the same output

🔒 PRIVACY_SENSITIVE_FIELD
Privacy
Blocks actions targeting password fields, payment fields (cc-number, cc-csc), or new-password autocomplete fields.
🔒 PRIVACY_PII_SUBMISSION
Privacy
Blocks form submissions containing PII patterns (email, phone, SSN). Prevents accidental data exposure.
🔒 PRIVACY_FORM_AUTOFILL
Privacy
Blocks autofill of sensitive form fields to prevent unintended disclosure of personal data.
⚠️ SAFETY_UNLABELED_CONTROL
Safety
Blocks clicks on controls with no accessible name. Unknown purpose = unsafe to interact with.
⚠️ CONTEXT_RESTRICTED
Safety
Blocks execution on chrome:// and extension:// pages. Only read-only commands (describe screen) are allowed.
